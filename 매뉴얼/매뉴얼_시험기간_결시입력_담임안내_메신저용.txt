[전자칠판] 시험 기간 결시자 입력 안내 (담임 선생님)

✅ 시험 날에는 우리 반 전자칠판이 자동으로 시험 화면으로 바뀝니다.

✏️ 아침 조회 때 결시자 입력 (1분)
1. 전자칠판 오른쪽 아래 [결시자 입력] 터치
2. 담임 PIN 입력 (관리자 페이지 로그인 번호, 바꾸지 않았다면 2026)
3. 결석한 학생 번호 터치 (여러 명 가능, 교시는 자동 선택)
4. 사유 확인 → [결시 등록] 터치 → 끝!

🕘 지각한 학생이 시험을 봤다면
결시자 입력 → 그 학생의 교시 칸을 두 번 터치하면 삭제됩니다.

⚙️ 처음 한 번만
결시자 입력 창의 [재적·공번 설정]에서 우리 반 재적과 공번을 확인해 주세요.

👀 감독 선생님
전자칠판 오른쪽 결시 현황을 보고 답안지 봉투에 기록하시면 됩니다.

💻 교무실 PC에서도 가능: 관리자 페이지 → [시험 결시 입력]
🔒 결시 기록은 전자칠판에만 저장되며 고사 관리 프로그램과는 별개입니다.

자세한 그림 안내는 첨부 파일을 참고해 주세요.
