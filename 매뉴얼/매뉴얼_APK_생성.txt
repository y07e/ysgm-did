═══════════════════════════════════════════════════════════════
  양산여중 전자칠판 DID — APK 생성 및 배포 가이드
═══════════════════════════════════════════════════════════════
  적용 대상: 시스템 담당 교사
  생성 도구: PWA Builder (https://www.pwabuilder.com)
  소요 시간: 약 15분 (첫 회), 5분 (재생성)
═══════════════════════════════════════════════════════════════


【 개요 】

  웹사이트(https://ysgm-did.web.app)를 안드로이드 APK로 패키징하여,
  IFP에 일반 앱처럼 설치할 수 있게 만드는 절차입니다.

  결과물: ysgm-did.apk (약 1~5 MB)
  방식: TWA (Trusted Web Activity) — 구글 공식 PWA→APK 변환

  앱이 하는 일:
    1) 첫 실행 시 학년/반 선택 화면 (start 페이지) 표시
    2) 선택한 학급을 기억 (localStorage에 저장)
    3) 다음 실행부터 5초 카운트다운 후 자동으로 학급 화면 표시
    4) 학급 변경 필요 시 시작 페이지에서 다시 선택 가능


═══════════════════════════════════════════════════════════════
  Part 1. APK 생성 (PWA Builder)
═══════════════════════════════════════════════════════════════

【 Step 1. PWA Builder 접속 】

  1) Chrome 브라우저로 https://www.pwabuilder.com 접속
  2) 중앙 입력칸에 URL 입력:

        https://ysgm-did.web.app

  3) "Start" 버튼 클릭


【 Step 2. PWA 점수 확인 】

  PWA Builder가 사이트를 자동 분석합니다 (10초 소요).

  표시되는 점수:
    · Manifest:    100점 (또는 90+)
    · Service Worker: 100점
    · Security:    100점

  → 모두 녹색이면 OK. 노란색/빨간색이면 표시되는 문제를 확인.


【 Step 3. Android 패키지 생성 】

  1) 우측 상단 "Package for stores" 버튼 클릭
  2) 표시되는 플랫폼 중 "Android" 카드 → "Generate Package"
  3) 설정 화면에서 아래 값으로 입력:

     ┌─────────────────────┬────────────────────────────────────┐
     │ Package ID          │ kr.school.ysgm.did                 │
     │ App Name            │ 양산여중 알림판                     │
     │ Launcher Name       │ 양산여중 알림판                     │
     │ App Version         │ 1.0.0                              │
     │ App Version Code    │ 1                                  │
     │ Host                │ ysgm-did.web.app                   │
     │ Start URL           │ /start/                            │
     │ Display Mode        │ Fullscreen                         │
     │ Status Bar Color    │ #1e293b                            │
     │ Navigation Color    │ #1e293b                            │
     │ Background Color    │ #0f172a                            │
     │ Theme Color         │ #1e293b                            │
     │ Splash Color        │ #0f172a                            │
     └─────────────────────┴────────────────────────────────────┘

  4) "Signing key" 섹션:
     · "New" 선택 → 자동으로 새 서명 키 생성
     · "Key alias": android (기본값 유지)
     · "Key Password / Store Password": 임의의 비밀번호 입력
       예: ysgm2026 (잊지 말 것! 추후 업데이트 시 필요)

  5) "Download" 버튼 → ZIP 파일 다운로드

     다운로드된 파일: ysgm-did.zip (약 5 MB)


【 Step 4. ZIP 내용 확인 】

  ZIP 파일을 압축 해제하면:

    ysgm-did/
    ├── app-release-signed.apk    ← 이 파일이 IFP에 설치할 APK
    ├── app-release-bundle.aab    ← Google Play 등록용 (사용 안 함)
    ├── signing.keystore          ← 서명 키 (안전한 곳에 보관!)
    ├── assetlinks.json           ← 우리 사이트에 업로드할 파일
    └── README.md

  ⚠️ signing.keystore 파일은 절대 분실하지 마세요.
     이 파일이 있어야 다음 버전 업데이트 가능.
     백업 권장: 학교 클라우드 또는 USB.


═══════════════════════════════════════════════════════════════
  Part 2. 디지털 자산 연결 설정 (전체화면 활성화)
═══════════════════════════════════════════════════════════════

이 단계를 건너뛰면 APK가 상단에 작은 URL 바를 표시합니다.
키오스크용으로 사용하려면 반드시 진행하세요.


【 Step 1. APK 서명 지문(SHA-256) 추출 】

  PWA Builder가 다운로드한 README.md 파일을 열어보면
  "Digital Asset Links" 섹션에 SHA-256 지문이 적혀있습니다.

  형태 예시:
    AB:CD:EF:12:34:56:...:FF (총 64자리, 콜론 32개)

  이 값을 복사해 두세요.


【 Step 2. 프로젝트의 assetlinks.json 수정 】

  파일 위치: /Users/kengwanyoon/전자칠판DID/.well-known/assetlinks.json

  텍스트 에디터로 열어서 아래 부분을 교체:

    "REPLACE_WITH_APK_SHA256_FINGERPRINT_AFTER_GENERATING_APK"

    → 위에서 복사한 실제 SHA-256 값으로 교체

  수정 후 저장.


【 Step 3. 재배포 】

  터미널에서:

    cd /Users/kengwanyoon/전자칠판DID
    firebase deploy --only hosting

  → 약 30초 후 배포 완료


【 Step 4. 적용 확인 】

  브라우저에서 직접 확인:

    https://ysgm-did.web.app/.well-known/assetlinks.json

  → 위에서 입력한 SHA-256 값이 표시되면 성공


═══════════════════════════════════════════════════════════════
  Part 3. IFP에 APK 설치
═══════════════════════════════════════════════════════════════

【 Step 1. IFP 설정 (1회만) 】

  안드로이드 11 기준:
  1) IFP 설정 → 앱 및 알림 (또는 "앱")
  2) 우측 상단 ⋮ → 특별한 앱 액세스
  3) "알 수 없는 앱 설치"
  4) 목록에서 "파일 관리자" (또는 Chrome) 선택 → "이 출처에서 허용" ON


【 Step 2. APK를 IFP로 전송 (3가지 방법) 】

  ▶ 방법 A. USB 메모리 (가장 안정)
    1) PC에서 app-release-signed.apk를 USB에 복사
    2) IFP에 USB 꽂기
    3) 파일 관리자 앱으로 USB 열기 → APK 더블탭

  ▶ 방법 B. 학교 클라우드/메일
    1) Google Drive 또는 학교 메일로 APK 업로드
    2) IFP Chrome으로 다운로드
    3) 다운로드 알림 클릭 → 설치

  ▶ 방법 C. 같은 와이파이 직접 전송 (LocalSend 등)
    1) 양쪽에 LocalSend 앱 설치 (PC + IFP)
    2) 같은 와이파이 → 직접 전송


【 Step 3. APK 설치 】

  1) APK 파일 탭
  2) "이 앱을 설치하시겠습니까?" 화면 → "설치"
  3) 10초 대기 → "앱 설치됨"
  4) "열기" 클릭


【 Step 4. 첫 실행 — 학급 선택 】

  1) 앱 첫 실행 시 학년 선택 화면 표시
  2) 1학년 / 2학년 / 3학년 중 해당 학년 탭
  3) 반 선택 (예: 1학년 9반)
  4) 자동으로 학급 화면 표시
  5) 이후로는 앱 실행 시 5초 카운트다운 후 자동 진입


【 Step 5. 부팅 시 자동 실행 (선택) 】

  IFP가 켜질 때마다 자동으로 앱이 실행되게 하려면:

  방법 A. NEXWIN 자체 설정 (있다면)
    설정 → 시스템 → "Startup Application" → "양산여중 알림판" 선택

  방법 B. 별도 자동 실행 앱 사용
    "Autostart - No Root" 같은 무료 앱 설치 후
    양산여중 알림판을 부팅 자동 실행 등록


═══════════════════════════════════════════════════════════════
  Part 4. 학급 변경 / 재설정
═══════════════════════════════════════════════════════════════

【 학급 변경하고 싶을 때 】

  방법 A. 시작 페이지에서 변경
    1) 앱 실행 → 5초 카운트다운 화면에서 "취소" 또는 "다른 학급" 버튼
    2) 학급 선택 화면으로 돌아감
    3) 새 학년/반 선택

  방법 B. 앱 데이터 초기화 (강제 리셋)
    1) IFP 설정 → 앱 → "양산여중 알림판"
    2) "저장공간" → "데이터 삭제"
    3) 앱 다시 실행 → 학급 선택 화면 첫 화면 표시


═══════════════════════════════════════════════════════════════
  Part 5. 업데이트 (새 버전 배포)
═══════════════════════════════════════════════════════════════

【 웹 코드만 수정한 경우 】

  → APK 재생성 불필요!
     firebase deploy만 하면 APK가 다음 실행 시 자동으로 최신 웹 코드를 로드.
     (TWA 방식의 가장 큰 장점)


【 manifest.json, 앱 아이콘 등이 변경된 경우 】

  → APK 재생성 필요

  절차:
  1) PWA Builder에서 다시 패키지 생성
     ⚠️ App Version Code는 반드시 +1 (예: 1 → 2)
  2) Signing key 섹션에서 "Existing" 선택
  3) 첫 회에 다운받은 signing.keystore 파일 업로드
  4) 비밀번호 입력 (첫 회에 설정한 값)
  5) 새 APK 다운로드 → IFP에 덮어쓰기 설치
     (서명 키가 같으면 기존 앱 데이터 유지됨)


═══════════════════════════════════════════════════════════════
  Part 6. 트러블슈팅 / FAQ
═══════════════════════════════════════════════════════════════

Q. APK 설치 시 "앱이 설치되지 않음" 오류
A. 1) "알 수 없는 출처" 설치 허용 확인 (Part 3 Step 1)
   2) 기존 같은 패키지명 앱이 설치되어 있으면 먼저 제거
   3) 다른 서명으로 빌드된 같은 패키지명 앱이면 제거 후 재설치

Q. 앱 실행 시 상단에 URL 바가 보임
A. assetlinks.json 설정이 안 된 상태.
   Part 2 절차 진행 후 IFP 앱 데이터 삭제 → 재실행.

Q. "Chrome이 필요합니다" 메시지
A. TWA는 Chrome 엔진을 사용하므로 IFP에 Chrome이 설치되어 있어야 함.
   NEXWIN IFP는 보통 Chrome이 기본 설치되어 있어 문제없음.

Q. 학급을 잘못 선택했음
A. Part 4 참고 — 시작 페이지에서 학급 변경 또는 앱 데이터 초기화.

Q. 29개 학급 모두 같은 APK 설치 가능?
A. 네. 같은 APK가 각 IFP에서 독립적으로 학급 선택 정보를 저장합니다.
   학급마다 다른 APK 만들 필요 없음.

Q. APK 크기를 더 줄이려면?
A. PWA Builder의 기본값으로도 5 MB 이하라 충분히 작습니다.

Q. 업데이트 시 학생들이 본 데이터(localStorage 학급 정보)가 사라지나?
A. 같은 서명 키로 업데이트하면 유지됩니다.
   다른 서명 키로 빌드하면 기존 앱을 제거해야 하므로 데이터 손실.
   → 그래서 signing.keystore 파일을 잘 보관해야 함.


═══════════════════════════════════════════════════════════════
  📦 백업 권장 파일 (분실 시 재생성 어려움)
═══════════════════════════════════════════════════════════════

  · signing.keystore       — APK 서명 키 (재생성 불가, 분실 시 새 키 + 기존 앱 제거 필수)
  · Key Password           — 위 키의 비밀번호
  · README.md (SHA-256)    — 디지털 자산 연결용

  이 3가지는 학교 클라우드 + USB 등 2곳 이상에 백업 권장.
