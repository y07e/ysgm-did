═══════════════════════════════════════════════════════════════
  적용 대상: 전자칠판 초기 설정 담당자 (학교 IT 담당, 기사 등)
  발행일: 2026년 5월
═══════════════════════════════════════════════════════════════


【 전자칠판 환경 】

  • OS: 안드로이드 10 (NEXWIN W62B 기준)
  • 브라우저: Chrome 148+
  • 해상도: 3840 × 2160 (4K, DPR 4 → CSS 뷰포트 960×484)
  • 인터넷 연결 필수 (Wi-Fi 또는 유선)


══════════════════════════════════════════════════
  📺 학급별 전자칠판 초기 설정 (1회만)
══════════════════════════════════════════════════

▶ 방법 1: 셋업 페이지 사용 (권장)

  1단계: 전자칠판 Chrome 열기

  2단계: 주소창에 입력
    https://ysgm-did.web.app/start/

  3단계: 학년·반 선택
    • 학년 드롭다운에서 해당 학년 선택
    • 반 드롭다운에서 해당 반 선택
    • "이 학급으로 설정" 버튼 클릭

  4단계: 5초 카운트다운 후 자동 이동
    • 학급 표시 화면(/display/)으로 자동 진입
    • URL에 ?grade=N&class=M&desktop=1 자동 부착

  5단계: 홈 화면에 추가 (영구 설정)
    • Chrome 메뉴 ⋮ (점 3개)
    • "홈 화면에 추가" 또는 "앱 설치" 선택
    • 이름: "○학년 ○반 알림판" 등으로 저장
    • → 다음부터 홈 화면 아이콘 한 번 탭으로 실행 ✨


▶ 방법 2: 직접 URL 입력

  주소창에 직접:
  https://ysgm-did.web.app/display/?grade=학년&class=반&desktop=1

  예시:
  • 1학년 7반: ?grade=1&class=7&desktop=1
  • 3학년 11반: ?grade=3&class=11&desktop=1


▶ 방법 3: USB 셋업 파일 (학년부장이 일괄 배포 시)

  USB에 "전자칠판_셋업_바로가기.html" 파일 복사
  → 전자칠판에서 파일 매니저로 열기
  → Chrome으로 열기 선택
  → 자동으로 셋업 페이지로 이동


══════════════════════════════════════════════════
  🖥️ 전체 화면 모드
══════════════════════════════════════════════════

전자칠판 알림판은 전체 화면(주소창 숨김) 사용을 권장합니다.

▶ 방법 1: PWA 설치 (가장 안정적, 영구)
  Chrome 메뉴 → "홈 화면에 추가"
  → 홈 화면 아이콘 실행 시 자동으로 주소창 없는 모드

▶ 방법 2: Chrome 전체화면
  Chrome 메뉴 → "전체 화면"
  (단, 일부 IFP는 미지원)

▶ 방법 3: 화면 우측 상단 "🔳 전체화면" 버튼
  화면 자체에 떠 있는 파란 버튼 클릭
  (Fullscreen API 지원 IFP만)

▶ 방법 4: 안드로이드 시스템 바 숨김
  전자칠판 설정 → 디스플레이 → 상태 바 숨김


══════════════════════════════════════════════════
  🔄 학급 변경 / 재설정
══════════════════════════════════════════════════

다른 반으로 변경하려면:

  1) 주소창에 https://ysgm-did.web.app/start/ 다시 입력
  2) 새 학년/반 선택 → 설정

  또는

  1) 화면 우측 상단 학급 표시 클릭 (작은 글씨)
  2) 셋업 페이지로 이동


══════════════════════════════════════════════════
  🆘 문제 해결
══════════════════════════════════════════════════

▶ 화면이 안 떠요 / 흰 화면
  • Wi-Fi 연결 확인
  • Chrome 새로고침 (메뉴 → 새로고침)
  • Chrome 캐시 삭제 (메뉴 → 설정 → 개인정보 → 방문기록 삭제)

▶ 글자가 너무 작아요 / 잘려서 보여요
  • 우측 상단 "🔳 전체화면" 클릭해서 주소창 제거
  • 또는 PWA로 설치 (위 "전체 화면 모드" 참고)

▶ 정보가 안 갱신돼요
  • 새로고침 (F5 또는 Chrome 메뉴 → 새로고침)
  • 1분 정도 기다림 (실시간 동기화)
  • Wi-Fi 끊김 확인

▶ 학급이 잘못 표시돼요
  • 위 "학급 변경 / 재설정" 절차로 다시 셋업

▶ 전자칠판이 멈춰있어요 / 화면 검정
  • Chrome 자체 재시작 (홈 화면 → Chrome 강제 종료 후 재실행)
  • IFP 자체 재부팅 (전원 OFF → ON)

▶ 새 정보 입력했는데 안 보여요
  • 관리자가 활성화 체크 했는지 확인
  • 대상 학년/반 설정 확인
  • 만료일 지났는지 확인

  ⏰ 일과 운영 권장
══════════════════════════════════════════════════

▶ 등교 전: 자동 켜기 (IFP 자체 스케줄러 활용)

  알림판은 24시간 켜놔도 OK (다크 모드 디자인)
  단, IFP 수명 위해 야간 OFF 권장

▶ Wi-Fi:
  학교 Wi-Fi 안정성 중요. 끊기면 마지막 데이터로 표시되다가
  복구되면 자동 동기화
