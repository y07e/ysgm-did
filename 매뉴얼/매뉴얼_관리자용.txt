  발행일: 2026년 5월 (최종 수정: 2026년 6월 — 결보강 PDF·담임 일괄등록 등 반영)

【 시스템 개요 】

• 양산여자중학교 29개 학급(1학년 9반, 2학년 9반, 3학년 11반)
  전자칠판 종합 알림판 시스템
• 인터넷 기반 — Firebase Hosting (https://ysgm-did.web.app)
• 관리자 1명 변경 → 29개 전자칠판 동시 실시간 반영
• 24시간 무인 운영 가능


【 주요 URL 】

▶ 관리자 페이지 (Google 로그인)
   https://ysgm-did.web.app/admin/

▶ 학급 표시 화면 (전자칠판/모바일)
   https://ysgm-did.web.app/display/?grade=학년&class=반&desktop=1

▶ 학급 셋업 페이지 (전자칠판 초기 설정)
   https://ysgm-did.web.app/start/

▶ 환경 진단 도구 (문제 발생 시)
   https://ysgm-did.web.app/info/


【 관리자 로그인 】

1) 관리자 페이지 접속
2) "관리자 (Google)" 탭 선택
3) 본인 Gmail 계정으로 로그인
   → 등록된 관리자만 진입 가능
   → 등록 안 된 경우 "관리자에게 등록 요청" 안내 후 자동 로그아웃


【 메뉴 구성 】

📢 공지사항 등록
  ├ 학교 공지: 전체/학년별/학급별 공지 등록
  └ 🚨 긴급 공지: 전체 화면 덮는 비상 알림

📅 일정 관리
  ├ 기초 시간표 편집: 학년/반/요일별 시간표 (학기 단위, NEIS 엑셀 업로드)
  ├ 📋 일일 시간표 변경: 특정 날짜의 시간표 변경
  │    └ 📄 결보강 PDF 업로드: 컴시간 결보강 PDF로 전체 반 일괄 변경
  ├ 🎯 D-Day: 시험·행사 카운트다운
  └ 📆 학사일정: 금주(월~일) 일정 표시 (항목별 'D-Day 설정' 버튼 제공)

🍱 급식 시간
  ├ 학급별 급식 시간 운영 기간 관리 (지난 달은 접힘)
  └ 월별 자동 순환 + 인쇄용 학급별 급식 순서표

📋 학급 게시판
  ├ 학급별 게시판 글 관리 (관리자도 등록 가능)
  └ 🔍 우리반 미리보기: 날짜 지정해 그날 화면 미리보기 가능

⚙️ 설정
  ├ 🏫 학교 설정: 학교명, 로고, NEIS 정보, 학년별 학급 수
  │    └ 학급 수 변경 시 저장만 하면 전체 반영 (코드 수정 불필요)
  ├ ⏰ 수업 시간 설정: 기초 수업 시간 / 단축 수업
  ├ 👥 교사 관리: 관리자/담임 등록·PIN 관리
  │    └ 📋 담임 일괄 등록: 부서표 PDF 또는 엑셀로 전체 담임 한 번에
  ├ 🔗 교실 URL: 전체 학급 직접 링크 목록
  └ 💾 백업·복원: 전체 데이터 JSON 백업 (항목별 개수 표시)


══════════════════════════════════════════════════
  📝 입력 가이드라인 (화면 깨짐 방지)
══════════════════════════════════════════════════

▶ 학교 공지사항
  • 제목: 15자 이내 권장 (LED 노란 제목 한 줄)
  • 내용: 줄당 25자 이내, 한 공지 9줄 이내
    → 3줄 단위로 자동 슬라이드 분할 (1/3), (2/3) 표시
  • 동시 활성: 3~5개 권장 (회전 주기 너무 길어지지 않게)
  • 대상: 전체 / 특정 학년·반 정확히 선택
  • Enter로 줄바꿈 가능 (LED 마키에서 줄 구분 표시)

▶ 🚨 긴급 공지 (정말 긴급할 때만 사용)
  • 제목: 10자 이내 (전체 화면을 덮는 큰 글씨)
  • 사용 후 반드시 해제 버튼 클릭 (자동 만료 없음)
  • 이력 자동 저장 → 재사용 가능 (📝 불러오기)

▶ 🎯 D-Day
  • 제목: 6자 이내 (예: "체육대회", "1학기 시험")
  • 동시 활성: 2개 권장 (톱바 가로 길이 제한, 잘림 방지)
  • 지난 일정은 ✓ 활성화 해제 또는 삭제
  • 아이콘(이모지) 1개 권장

▶ 📆 학사일정
  • 제목: 10자 이내 (예: "체육대회", "심폐소생술 교육")
  • 한 주 2건 권장 (좌측 패널 공간 제한)
  • 금주(월~일) 일정만 자동 표시됨 → 다음 주 일정은 그 주에 자동 노출
  • 지난 일정은 비활성화 권장 (목록 정리)

▶ 시간표
  • 기초 시간표: 학기 단위 1회 입력 (NEIS 엑셀 일괄 업로드 가능)
  • 일일 시간표 변경: 특정 날짜의 임시 변경
    → 자동으로 "변경" 빨간 배지 표시

▶ 단축 수업 (행사·체육대회 등 특별한 날)
  • 교시별 시작/종료 시각 정확히 입력
  • 점심 위치 (몇 교시 후) + 점심 시작/종료 반드시 입력
  • 점심 없는 날은 "점심 없음" 선택

▶ 급식 시간 운영 기간
  • 월별 운영 권장 (5월 운영, 6월 운영 ...)
  • 📋 다음 달 복제 버튼으로 빠르게 추가 (순환 이어받기 자동)
  • 주간 순환 ON: 매주 시작 학급 자동 회전


══════════════════════════════════════════════════
  🔧 주요 작업 흐름 (Frequently Done)
══════════════════════════════════════════════════

▶ 학교 공지 등록
  관리자 → 📢 공지사항 등록 → 학교 공지
  → 제목·내용·대상·만료일 입력 → 등록
  → 29개 전자칠판 즉시 반영

▶ 긴급 공지 전송 (화재·재난·일과 변경)
  관리자 → 📢 공지사항 등록 → 🚨 긴급 공지
  → 제목·내용 입력 → 🚨 즉시 전송
  → 사용 후 해제 버튼 반드시 클릭

▶ 담임 한 명 등록
  관리자 → ⚙️ 설정 → 👥 교사 관리
  → 이름·학년·반·PIN 입력 → 추가
  → PIN 비우면 해당 연도(예: 2027) 자동 / 담임이 PIN으로 로그인

▶ 담임 전체 일괄 등록 (신학기 — 가장 빠름)
  관리자 → ⚙️ 설정 → 👥 교사 관리 → "📋 담임 일괄 등록"
  → [방법A] 학교 부서표 PDF 그대로 업로드 (학급 담임 표 자동 인식)
  → [방법B] 엑셀 양식 다운로드 → 이름 입력 → 업로드
  → 미리보기 확인 → "기존 담임 전체 삭제 후 등록" 체크 → 일괄 등록
  → 약 30명 한 번에 (5분)

▶ 결보강 일괄 반영 (매일/수시)
  관리자 → 📅 일정 관리 → 일일 시간표 변경 → "📄 결보강 PDF 업로드"
  → 컴시간 결보강 PDF 선택 → 미리보기(원래수업 → 새수업) 확인
  → 선택 항목 적용 → 전체 반 변경분 한 번에 반영
  ※ 특별보강은 화면에 보라색 "특별보강" 배지로 표시됨

▶ 신학기 학급 수 변경 (학급 증감 시에만)
  관리자 → ⚙️ 설정 → 🏫 학교 설정
  → 학년별 학급 수 입력 → 💾 학교 설정 일괄 저장
  → 학급 목록·시간표·교실 URL 즉시 전체 반영 (코드 수정 불필요)

▶ 신학기 시간표 일괄 입력 (3월)
  관리자 → 📅 일정 관리 → 기초 시간표 편집
  → 📤 나이스 시간표 엑셀 업로드 → 파일 선택 → 미리보기
  → 전체 학급에 적용
  → 3개 학년 (3개 파일) 약 5분 만에 전교 입력 완료

▶ 학사일정을 D-Day로 등록
  관리자 → 📅 일정 관리 → 📆 학사일정
  → 등록된 일정 항목의 "🎯 D-Day 설정" 버튼 클릭
  → 자동으로 D-Day 등록 (다시 누르면 해제)

▶ 행사일 단축 수업 설정 (학교 축제·체육대회 등)
  관리자 → ⚙️ 설정 → ⏰ 수업 시간 설정
  → 📅 단축 수업 일 시간 설정 카드
  → 날짜 선택 → 📋 기초 시간 불러오기
  → 교시 시간 수정 + 점심 위치·시간 입력
  → 💾 단축 수업 저장

▶ 다음 달 급식 운영 기간 추가
  관리자 → 🍱 급식 시간
  → 현재 운영 기간 카드의 📋 다음 달 복제 클릭
  → 자동으로 다음 달 1일~말일 설정 + 순환 이어받기
  → 💾 저장

▶ 데이터 백업 (학기말·학년말 권장)
  관리자 → ⚙️ 설정 → 💾 백업·복원
  → 📥 JSON 백업 다운로드

  ⚠️ 주의사항
══════════════════════════════════════════════════

▶ 관리자 권한
  • Google 로그인한 후 등록되어 있어야 진입 가능
  • 등록되지 않은 외부인은 자동 로그아웃 (보안)
  • 새 관리자 추가는 기존 관리자가 👥 교사 관리에서 등록

▶ 데이터 변경
  • 모든 변경은 즉시 전자칠판 29개에 반영됨
  • 실수로 잘못 등록해도 즉시 수정/삭제 가능
  • 백업 권장: 학기말, 학년말, 큰 변경 전

▶ 긴급 공지
  • 전체 화면을 덮으므로 신중하게 사용
  • 사용 후 반드시 해제 (자동 만료 X)

▶ 학년 통합 변경 (예: 학년/반 수 변경)
  • config.js 수정 + 재배포 필요
  • 시스템 관리자에게 요청


══════════════════════════════════════════════════
  🆘 자주 묻는 질문 (FAQ)
══════════════════════════════════════════════════

Q. Google 로그인 했는데 "등록되지 않은 계정"이라고 나와요.
A. 다른 관리자가 👥 교사 관리에서 본인 이메일을 등록해야 합니다.

Q. 공지 등록했는데 전자칠판에 안 보여요.
A. 1) 새로고침(F5) 시도, 2) 대상 학년/반 설정 확인, 3) 활성화 체크 여부 확인.

Q. 전자칠판이 멈춰있어요.
A. 전자칠판 Chrome 새로고침. 그래도 안 되면 IFP 자체 재부팅.

Q. 잘못 등록한 데이터를 되돌리고 싶어요.
A. 최근 백업이 있다면 ⚙️ 설정 → 💾 백업·복원에서 복원 가능.
   백업 없이는 개별 삭제만 가능.

Q. 학년/반 정보가 틀려요 (1학년이 9반인데 8반까지만 나옴).
A. config.js의 gradeClasses 설정 + 재배포 필요. 시스템 관리자 문의.
