═══════════════════════════════════════════════════════════════
  적용 대상: 각 학급 담임 교사
  발행일: 2026년 5월
═══════════════════════════════════════════════════════════════


【 우리반 전자칠판이 보여주는 정보 】

전자칠판에는 다음 정보가 실시간 자동 표시됩니다:

  ✓ 학교 전체 공지사항 (학교 관리자 등록)
  ✓ 우리반 학급 게시판 (담임이 등록)
  ✓ 오늘 시간표 (기초 + 일일 변경)
  ✓ 우리반 급식 시간
  ✓ 양산 날씨·미세먼지
  ✓ D-Day 카운트다운 (시험·체육대회 등)
  ✓ 금주 학사일정
  ✓ 긴급 공지 (있을 때만 전체 화면)

  → 모든 정보 자동 갱신, 새로고침 불필요
  → 담임은 "학급 게시판"과 "일일 시간표 변경"만 관리


【 담임이 할 수 있는 것 】

  ✅ 우리반 학급 게시판 글 등록·수정·삭제
  ✅ 우리반 일일 시간표 변경 (체험학습 등 특정 날짜만)
  ❌ 학교 전체 공지 등록 (불가)
  ❌ 기초 시간표 편집 (불가)
  ❌ 다른 반 데이터 접근 (불가)


══════════════════════════════════════════════════
  🔐 담임 로그인 방법
══════════════════════════════════════════════════

▶ 1단계: 관리자 페이지 접속
  • PC/스마트폰 Chrome에서:
    https://ysgm-did.web.app/admin/

▶ 2단계: 담임교사 탭 선택
  • 화면 상단의 "👨‍🏫 담임교사" 버튼 클릭
    (기본은 "관리자(Google)" 탭이므로 변경 필요)

▶ 3단계: 본인 정보 입력
  • 학년 선택 (예: 2학년)
  • 반 선택 (예: 5반)
  • 본인 이름 선택 (드롭다운에서)
  • PIN 입력 (관리자가 발급한 비밀번호)
  • 로그인 버튼

▶ 4단계: 우리반 관리 메뉴 진입
  • 좌측 메뉴에 두 가지 탭만 보임:
    📋 내 학급 게시판
    📋 일일 시간표 변경


══════════════════════════════════════════════════
  📋 학급 게시판 사용법
══════════════════════════════════════════════════

▶ 새 글 등록
  1) 📋 내 학급 게시판 탭
  2) 제목·내용·만료일(선택) 입력
  3) "학급 게시판에 등록" 클릭
  4) → 우리반 전자칠판에 LED 마키로 즉시 흘러나옴

▶ 등록된 글 수정/삭제
  • 하단 목록에서 ✏️ 수정 / 🗑 삭제 버튼

▶ 미리보기 (어떻게 보이는지 확인)
  • 상단 "📺 새 창으로 열기" 클릭
  • → 우리반 전자칠판 화면 그대로 새 창에 표시
  • 모바일 사이즈로 보고 싶으면 "📱 모바일" 클릭

▶ 입력 가이드라인 (화면 깨짐 방지)
  • 제목: 15자 이내 권장 (LED 노란 제목)
  • 내용: 줄당 30자 이내 권장 (마키로 흐름)
  • 동시 활성 글: 3개 이내 권장
  • 만료일 설정 권장 (예: 행사 다음 날)
    → 자동으로 안 보이게 처리됨

▶ 좋은 예
  제목: "내일 체육복 가져오기"
  내용: "내일 1교시 체육 / 체육복 + 운동화 필수"
  만료일: 내일 다음 날

▶ 피해야 할 예
  제목: "안녕하세요 2학년 5반 친구들 오늘 알려드릴 사항이 있는데요"
       → 너무 길어서 LED에서 잘림
  내용: (5문단 이상의 긴 글)
       → 마키 회전 시간이 너무 길어 가독성 ↓


══════════════════════════════════════════════════
  📋 일일 시간표 변경 사용법
══════════════════════════════════════════════════

▶ 사용 상황
  • 체험학습으로 평소 시간표와 다른 날
  • 시험 기간 임시 변경
  • 특정 교시 자습으로 변경 등

▶ 입력 방법
  1) 📋 일일 시간표 변경 탭
  2) 날짜 선택 (월/일 드롭다운, 기본은 오늘)
  3) 학년/반 자동 본인 학급 선택됨
  4) 각 교시별로 변경할 과목 선택
     → "원래 수업" 선택 시 기초 시간표 적용
     → 다른 과목 선택 시 빨간 "변경" 배지 표시
  5) "💾 변경 저장" 클릭

▶ 등록된 변경 확인/삭제
  • 우측 "📅 일일 시간표 변경 목록"에서 확인
  • 수정/삭제 가능
  • "🖨️ 출력" 버튼으로 인쇄 양식 출력 가능

▶ 자동 정리
  • 지난 날짜 변경은 표시 안 됨 (수동 삭제 권장)


══════════════════════════════════════════════════
  💡 자주 묻는 질문 (FAQ)
══════════════════════════════════════════════════

Q. PIN을 잊었어요.
A. 학교 관리자에게 PIN 재설정 요청.
   (관리자가 👥 교사 관리에서 새 PIN 발급)

Q. 다른 반 게시판은 못 보나요?
A. 담임은 본인 학급만 관리 가능. 다른 반 전자칠판을 보고
   싶으면 그 반의 학급 표시 URL로 직접 접속:
   https://ysgm-did.web.app/display/?grade=2&class=5

Q. 글 등록했는데 전자칠판에 안 나와요.
A. 1) Chrome 새로고침(F5),
   2) 만료일이 이미 지났는지 확인,
   3) 학년/반 확인 (본인 학급 맞는지),
   4) 1분 정도 기다림 (실시간 동기화 지연 시).

Q. 공지를 너무 길게 썼더니 화면이 답답해 보여요.
A. 짧게 나눠서 여러 개 등록하거나 핵심만 추려 작성 권장.
   LED 마키는 짧을수록 자주 보이고 효과적입니다.

Q. 만료일을 안 정하면 어떻게 되나요?
A. 만료 없음 = 영구 표시. 직접 삭제할 때까지 계속 보임.
   행사·이벤트성 공지는 만료일 설정 권장.

Q. 휴대폰에서도 사용 가능한가요?
A. 네. 같은 URL로 접속하면 모바일에 최적화되어 보임.
   집에서 다음 날 시간표 변경 미리 등록 가능.

Q. 우리반 전자칠판이 멈췄어요.
A. 전자칠판 Chrome 새로고침. 안 되면 행정실에 알림.

Q. 잘못 등록한 공지를 빨리 지우고 싶어요.
A. 하단 목록에서 🗑 삭제 즉시 가능. 전자칠판도 즉시 갱신.
