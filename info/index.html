📺 전자칠판 환경 진단

이 페이지를 전자칠판 Chrome에서 열어주세요. PC에서 같은 환경 재현에 필요한 값들이 표시됩니다.

📐 화면 크기 (CSS Pixels)

window.innerWidth (CSS 뷰포트 폭)
window.innerHeight (CSS 뷰포트 높이)
screen.width (스크린 폭)
screen.height (스크린 높이)
window.devicePixelRatio (DPR)
실제 물리 해상도 (계산값)

🌐 브라우저 정보

사용자 에이전트 (User Agent)
플랫폼
언어
터치 지원
전체화면 API 지원

💾 PC Chrome DevTools 설정용

아래 값들을 PC Chrome DevTools 디바이스 모드에 그대로 입력하세요:

Width × Height (px)
Device pixel ratio
User agent
💡 PC Chrome에 설정 방법:
1. F12 (DevTools 열기) → Ctrl+Shift+M (디바이스 모드)
2. 상단 디바이스 선택 → "Edit..." → "Add custom device"
3. 위 값들 그대로 입력 → Save
4. 추가한 디바이스 선택 → 정확한 IFP 환경 재현 완료
